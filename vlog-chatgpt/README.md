# Vlog „6 hodin řídí náš den ChatGPT“ — grafika

## Workflow
1. **Hlavní transkript** (celé video, titulky s časy) → pochopím děj a rozdělím ho na sekvence 1…N.
2. **Screen record chatu** → vytáhnu přesné texty promptů a odpovědí (co je v chatu doslova).
3. **Klipy** (exporty úseků, kde se čte) → spáruju s hlavním transkriptem a se zprávou v chatu.
4. Ke každé sekvenci: prompt pro Claude Design (karta + text + postupné zvýrazňování
   synchronizované s tím, jak to on čte) a seznam, co k tomu případně přiložit.

## Komponenty
- `01` Thinking animace (tři tečky) — základ, viz `01-thinking-animace-prompt.md`
- `02` Zpráva od ChatGPT — text se objevuje a zvýrazňuje slovo po slovu podle čtení
- `03` Naše zpráva do chatu („Mám hotovo, co dál?“) — modrá bublina vpravo
- Varianty podle obsahu sekvence: odpočet času (např. „20 min“), číslo od lidí,
  seznam úkolů, „přepsání“ zadání, když jsme chtěli jiný úkol
